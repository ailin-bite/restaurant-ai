# AI Restaurant Manager

Система поддержки принятия решений для менеджера ресторана.

ИИ не управляет рестораном и не заменяет менеджера или официанта. Он анализирует
данные зала, обнаруживает проблемы, прогнозирует ситуацию на 30–60 минут вперёд,
объясняет причину и предлагает действие. Применяет решение всегда человек.

```
Данные ресторана → метрики → AI-анализ → проблема → прогноз
   → объяснение → рекомендация → решение менеджера → измерение результата
```

Архитектура, схема базы, список endpoints и порядок разработки: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Состояние разработки

| Этап | Статус |
|---|---|
| 1. Архитектура и схема данных | готово |
| 2. Слой данных: модели + демонстрационные данные | готово |
| 3. Backend-скелет и движок метрик | следующий |
| 4–12. Интерфейс, правила, AI, симуляция, измерение результата | запланировано |

## Запуск слоя данных

Нужен Python 3.9+.

```bash
cd backend
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env          # и подставить OPENAI_API_KEY
.venv/bin/python -m app.db.seed.run --reset
```

База создаётся в `backend/data/restaurant.db`. Зерно генератора фиксировано,
поэтому состояние ресторана воспроизводимо и демонстрацию можно повторить.

## Что содержат демонстрационные данные

Ресторан «Терра»: 18 столиков в четырёх зонах, 20 блюд, 26 продуктов,
смена из 12 человек, 14 постоянных гостей с предпочтениями.

Данные подобраны так, чтобы будущий движок правил нашёл в них реальные проблемы,
а не искусственно вписанные сообщения:

- **узкое место кухни** — на гриле 10 позиций в работе против 4 на холодном цехе;
- **задержки** — 2 заказа превысили обещанные 25 минут, среднее ожидание 20 минут;
- **риск нехватки продукта** — куриной грудки осталось 8 порций;
- **наплыв броней** — 4 брони в ближайшие 30 минут и 8 в течение часа;
- **проблема обслуживания** — столик 10 занят 52 минуты без принятого заказа;
- **повторяющаяся жалоба** — около трети негативных отзывов недели про ожидание;
- **персонализация** — например, Мария Левина: 4 визита, вегетарианские блюда,
  не любит острое, любимое блюдо — паста.

## Технологии

Backend: Python + FastAPI + SQLAlchemy, база SQLite, AI-слой на OpenAI API.
Frontend: React + TypeScript + Tailwind CSS, графики на Recharts.

Для фронтенда понадобится Node.js — на машине он пока не установлен.
